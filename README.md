One image that sums up the world news of Wednesday 18 November 2026, drawn as
"The Daily Edition" broadsheet front page: the Gulf escalation as the hero
(U.S. strike on Qeshm Island, five tankers destroyed, drones over Bahrain),
columns on the Kerch Bridge's second day, Trump's Asia tour opening in
Manila and Ebola doubling in DR Congo, a Day in Numbers sidebar, and the
day's wire briefs along the bottom. The picture is drawn programmatically
by `build_image.py` (Pillow, deterministic) and delivered by `main.py`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
# writes out/entry.png — a whole PNG, 1024x1024, under the 1 MiB gate
```
